# EF Core Migrations Demo

Shows how to make the setup for EF Core Migrations and generate/update the database.

## Git Branches

- `00-entity-framework`
  - Application using EF Core to access Orders from an existing database.
  - Assuming database is manually created.

- `01-create-migration`
  - Configure EF Core Migrations to create/update the database based on the domain model from C#.
  - Create an initial migration.
